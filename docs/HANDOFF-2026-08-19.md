## 3. 실측 데이터 (이번 세션에서 측정)

### 3-1. 수집 범위
- 현재 28개 게시기관 필터의 **실제 커버리지 10.4%** (하루 전체 1,884건 중 195건)
- 전체 수집 시 **9.7배**. 단 게시기관 28개로도 **수요기관 2,075곳**이 커버됨(조달청 대행 구조)

### 3-2. DB 용량
- v1 덤프 복원 후 **Supabase 185MB / 500MB** (로컬 도커 복원 시 141MB)
- 공고 25,489건(라이브 1,471) · 첨부 56,050 · 자격요건 25,211 · 매칭 14,310 · 회사 11
- 보관 정책별 추정(전체 수집 기준): 30일 보관 ≈ 235MB, 60일 ≈ 400MB, 전체 ≈ 1.3GB
- **벡터 예산 약 315MB**

### 3-3. 청킹 (v1 chunker 768자 기준, 실제 첨부 84문서 실측)
- 공고당 **중앙값 55청크 / 평균 114** (최대 1,443)
- 문서 페이지 중앙값 7p, 공고당 텍스트 평균 57,159자
- 절감 시뮬레이션: 앞5페이지 39.6% · 문서당20청크 37.3% · **문서당10청크 20.0%** · **문서당5청크 10.2%**
- 유형 필터(설계·내역·서식 제외)는 3.2%만 절감 — **길이 상한이 훨씬 효과적**

### 3-4. 임베딩 제공자 (핵심 미결 사항)
| 후보 | 한도 | 차원 | 판정 |
|---|---|---|---|
| Gemini `gemini-embedding-001` | **하루 1,000요청** (배치 항목도 개별 카운트) | 3072/1536/768/256 MRL | 초기 9만건에 90일 → **운영 불가** |
| NVIDIA `nemotron-3-embed-1b` | **시간당 5.5만건**(초당 15.4) | **2048 고정**(축소 불가) | 처리량 OK, **용량 360MB로 예산 초과** |
| NVIDIA `nv-embedqa-e5-v5` | — | 1024 | **512토큰 제한** — 한국어 300자도 초과, 사용 불가 |
| NVIDIA `baai/bge-m3` | — | 1024 | 500 에러, 사실상 종료 |
| 자체 임베딩(Actions에서 오픈모델) | 무제한 | 모델 선택 | **미측정 ← 다음 작업** |

→ 남은 선택지: (a) Nemotron + 청크 3개로 축소 (b) Nemotron + 벡터 외부 DB 분리
   (c) 자체 임베딩 (d) 조합. **자체 임베딩 속도 측정 후 결정.**

### 3-5. Supabase 검증 결과
- PostgreSQL 17.6, 확장 **pgvector 0.8.2 · PGroonga 3.2.5** 설치 완료
- `compute_match_results()` 정상 (5.0초) / matview REFRESH CONCURRENTLY 정상 (1.2s, 3.5s)

### 4-3. 시크릿 (git에 없음 — 수동 이관 필요)
`bidding-agent/.env`에 있는 키 목록:

| 키 | 용도 | 상태 |
|---|---|---|
| `G2B_SERVICE_KEY` | 나라장터 OpenAPI (Decoding 키) | 유효 |
| `NVIDIA_API_KEY` | LLM 추출 + 임베딩 후보 | 유효 |
| `GEMINI_API_KEY` | 임베딩 후보 | 유효(한도 제약) |
| `SUPABASE_DB_URL` | v2 DB (Session pooler 5432) | 유효 |
| `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | Workers AI(임베딩) / R2 예정 | 확인 필요 |
| `AWS_BEARER_TOKEN_BEDROCK` | v1 잔재 | 폐기 대상 |

이관 방법: 비밀번호 관리자나 암호화된 채널로 `.env` 자체를 옮긴다. **레포에 커밋 금지.**

### 4-4. v1 데이터 원본
`bidmate_final.dump` (PostgreSQL custom format, 13.8MB, 2026-08-14)
— Supabase에 이미 복원 완료. 재복원이 필요하면 이 파일을 옮길 것. **레포에 넣지 말 것.**

```bash
pg_restore -d "$SUPABASE_DB_URL" --no-owner --no-privileges --schema=public -j 2 bidmate_final.dump
```
